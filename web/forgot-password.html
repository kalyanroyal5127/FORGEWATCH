Recover your password

Email delivery is not configured for this local academic project, so no reset email is sent. To safely reset an account on this computer, run this command from the project folder:

python -m backend.reset_password USERNAME

The command prompts privately for a new password, stores only its Werkzeug hash, and revokes existing API tokens for that account.
